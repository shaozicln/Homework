## 				**数据结构与算法课程设计**

#### 								链表：**206.反转链表**

#### 1、程序代码

 ```c++
#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode()
        : val(0), next(nullptr) {}
    ListNode(int x)
        : val(x), next(nullptr) {}
    ListNode(int x, ListNode* next)
        : val(x), next(next) {}
};

class Solution {
   public:
    ListNode* reverseList(ListNode* head) {
        ListNode* cur = head;
        ListNode* pre = nullptr;

        while (cur) {
            ListNode* temp = cur->next;
            cur->next = pre;
            pre = cur;
            cur = temp;
        }
        return pre;
    }
};

// 打印链表
void printList(ListNode* head) {
    ListNode* cur = head;
    while (cur) {
        cout << cur->val << " ";
        cur = cur->next;
    }
    cout << endl;
}

int main() {
    int t;
    cin >> t;
    cin.ignore();  // 忽略输入缓冲区中的换行符
    while (t--) {
        ListNode* head = nullptr;
        ListNode* cur = nullptr;
        string line;
        getline(cin, line);  // 读取一行输入
        if (!line.empty()) {
            istringstream s(line); // 允许像操作输入流（如cin）那样操作字符串。
            int value;
            while (s >> value) {  // 从当前行中读取值
                if (!head) {
                    head = new ListNode(value);
                    cur = head;
                } else {
                    cur->next = new ListNode(value);
                    cur = cur->next;
                }
            }
        }
        cout << "原始链表: ";
        printList(head);
        Solution s;
        ListNode* reversedHead = s.reverseList(head);
        cout << "反转后的链表: ";
        printList(reversedHead);

        // 释放链表内存
        while (reversedHead) {
            ListNode* temp = reversedHead;
            reversedHead = reversedHead->next;
            delete temp;
        }
    }
    return 0;
}
 ```

#### 3、实习总结与体会

不仅学习到了反转链表，还学习了如何像操作输入流（如cin）那样操作字符串。

（1）反转链表：`cur`指针初始化为链表的头节点用于遍历链表；`pre`指针初始化为空指针用于记录当前节点的前一个节点，反转后它将成为新链表的头节点。当所有节点都被反转后，`pre`指向新的头节点，即原链表的最后一个节点。返回`pre`作为反转后的新链表的头。

（2）按行读入输入数据：因为有`t`个测试用例，所以需要按行读入来分割多个测试用例。`cin.ignore()`用于忽略输入缓冲区中的换行符，确保后续的`getline`能够正确读取整行。`istringstream s(line)`用于将字符串流将行分割成多个整数。`while (s >> value)`用于逐个读取整数值。

（3）释放内存：遍历反转后的链表并释放每个节点的内存，防止内存泄漏。
